# Security Policy

Peerbots serves educators, therapists, families, and children — keeping our platform safe and private is a top priority.

## Reporting a Vulnerability

If you discover a security vulnerability in any Peerbots repository or hosted service, please **do not open a public GitHub issue**. Instead, disclose it privately using one of these channels:

1. **GitHub Private Vulnerability Reporting *(Preferred)***: Go to the repository's **Security** tab and click **"Report a vulnerability"** to open a private security advisory directly with Peerbots maintainers.
2. **Email**: Send details to [support@peerbots.org](mailto:support@peerbots.org?subject=%5BSecurity%5D%20Vulnerability%20Report).
3. **Web Form**: Submit via [Peerbots' Contact Us form](https://www.peerbots.org/contact).

## What to Include

- Affected repository or URL
- Clear steps to reproduce or proof-of-concept
- Potential impact (e.g., data exposure, unauthorized channel access, cost/quota abuse)

## Our Commitment

- We will acknowledge receipt within **3 business days**.
- We will investigate, ship a fix, and coordinate responsible public disclosure once users are protected.
- We will credit reporters in our advisory/changelog if they wish to be acknowledged.
